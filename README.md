# V6 — WhatsApp Group Bot

بوت واتساب للمجموعات باستخدام Node.js + JavaScript + Baileys + SQLite.

## المتطلبات

- Node.js 20 أو أحدث.
- رقم واتساب تريد ربطه بالبوت.
- المجموعة التي تريد تشغيل البوت فيها.

Baileys هو مكتبة غير رسمية للتعامل مع WhatsApp Web؛ استخدم البوت وفق شروط WhatsApp وبشكل مسؤول.

## التشغيل

```bash
npm install
npm start
```

في أول تشغيل سيظهر QR في الطرفية. امسحه من WhatsApp → الأجهزة المرتبطة → ربط جهاز.

### Pairing Code بدلاً من QR

افتح `config.js` وغيّر:

```js
pairingCode: true
```

ثم شغّل:

```bash
npm start
```

سيظهر كود الربط في الطرفية. الرقم يجب أن يكون دولياً بدون `+` أو مسافات، وهو مضبوط افتراضياً على رقم مالك البوت.

> ملاحظة: Pairing Code يعتمد على حالة WhatsApp/Baileys وقد تحدث أحياناً مشاكل بروتوكولية؛ إذا فشل، استخدم QR.

## الأوامر

### الكؤوس

```text
!setcoupe @الشخص 5
!coupe
!coupe @الشخص
```

`!setcoupe` يضيف إلى الرصيد الموجود ولا يستبدله.

### النقاط

```text
!setpoint @الشخص 500
!point
!point @الشخص
```

`!setpoint` يضيف إلى الرصيد الموجود ولا يستبدله.

### المتصدرون

```text
!top
```

يعرض Top 10 للكؤوس وTop 10 للنقاط.

### عام

```text
!menu
!help
!ping
```

## الصلاحيات

`!setcoupe` و`!setpoint` متاحان فقط لمالك البوت أو مشرف المجموعة.

رقم المالك في `config.js`:

```text
212710530141
```

## قاعدة البيانات

يتم إنشاء:

```text
data/v6.sqlite
```

وتحفظ قاعدة البيانات:

- WhatsApp JID
- الاسم
- الكؤوس
- النقاط

لذلك تبقى الأرصدة بعد إعادة تشغيل البوت.

## جلسة WhatsApp

يتم حفظ جلسة Baileys في:

```text
auth_info_baileys/
```

لا تشارك هذا المجلد ولا ترفعه إلى GitHub؛ يحتوي على مفاتيح جلسة حساسة.

إذا ظهر:

```text
statusCode: 401
```

يتوقف البوت عن إعادة الاتصال تلقائياً ويطلب منك إعادة ضبط الجلسة. احذف مجلد `auth_info_baileys` فقط إذا كنت تريد ربط رقم جديد، ثم شغّل البوت من جديد.

## ملاحظات تقنية

- يتم التعرف على الأشخاص بواسطة JID وليس الاسم فقط.
- أوامر التعديل تعتمد على `mentionedJid` الحقيقي من رسالة WhatsApp.
- الأرقام تقبل أعداداً صحيحة موجبة فقط حتى حد آمن.
- أخطاء معالجة الرسائل لا توقف البوت.
- إعادة الاتصال تلقائية بعد الانقطاعات العادية.
- 401 / Logged Out لا يدخل في حلقة إعادة اتصال.
