# WhatsApp Coupe & Point Bot

## الملفات
- `index.js`
- `package.json`
- `database.json`

## التشغيل
1. ثبت Node.js 20 أو أحدث.
2. افتح Terminal داخل مجلد البوت.
3. شغل:
   ```bash
   npm install
   npm start
   ```
4. الرقم المضبوط مسبقاً هو `+212710530141`. عند أول تشغيل اضغط Enter لاستعماله، أو أدخل رقماً آخر بالصيغة الدولية.
5. سيظهر لك Pairing Code. من واتساب:
   **الإعدادات → الأجهزة المرتبطة → ربط جهاز → الربط برقم الهاتف**
   ثم أدخل الكود.
6. من بعد الربط، الجلسة كتتحفظ فمجلد `auth_info_baileys` وما غاديش تحتاج تعاود الربط كل مرة.

## الأوامر
- `!coupe` → يشوف العضو عدد الكؤوس ديالو.
- `!point` → يشوف العضو عدد النقاط ديالو.
- `!top` → كيبين Top 10 فالكؤوس وTop 10 فالنقاط.
- `!setcoupe @الشخص` → للأدمن فقط، كيزيد كأس واحد للشخص.
- `!setpoint @الشخص 50` → للأدمن فقط، كيزيد 50 نقطة للشخص.

البوت كيرحب بالأعضاء الجدد تلقائيا.

## ملاحظة
كود Pairing في Baileys هو كود ربط من 8 خانات، وقد لا يكون أرقاما فقط حسب نسخة/تدفق واتساب؛ لا تحاول تحويله يدويا.
